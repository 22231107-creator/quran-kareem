# # Quran Kareem App 📖

A mobile application (Flutter) to help users memorize and revise the Quran.

## Planned features
- **Surah List:** browse surahs with memorization progress
- **Audio Player:** play a Qari's recitation and repeat each ayah
- **Progress:** track memorized pages, streaks, and weekly revision

## Modules & branches
| Module | Branch |
|---|---|
| UI (screens, surah list) | `feature/ui` |
| Audio (playback, repeat loop) | `feature/audio` |
| Progress (save & load) | `feature/progress` |

Workflow: `feature/*` → `dev` → `main`

## Current status
Sample project: the Surah List screen (`lib/main.dart`).
